# PetCare Assist

A mobile-first pet wellness, activity, rewards, and health-document companion.

## Prototype scope
- Pet profiles and photo upload
- Walking activity and statistics
- Care & Activity Score
- Wellness routines and observations
- PetCare Points rewards
- Gemini-ready AI assistant/document workflow

This repository contains a prototype. It does not provide veterinary diagnosis, insurance coverage decisions, or emergency medical advice.
